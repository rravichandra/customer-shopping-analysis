# Ecommerce SQL Analysis

A SQL-focused project for exploring ecommerce data, answering business questions, and documenting useful trends with queries and visualizations.

## Project Structure

```text
ecommerce-sql-analysis/
├── data/
│   └── raw/        # Place the 9 source CSV files here
├── sql/            # SQL query files
├── notebooks/      # Analysis and query-result exploration
├── images/         # Charts and other project visuals
└── README.md
```

## Data

Add the nine source CSV files to `data/raw/`. Keep the original files unchanged. Record the source, date downloaded, and any licensing or attribution requirements here before sharing the project.

## Analysis Workflow

1. Load the CSV files into your SQL database or analysis tool.
2. Review column names, data types, missing values, and duplicate records.
3. Save reusable analysis queries in `sql/`.
4. Use notebooks in `notebooks/` to run queries, summarize results, and create charts.
5. Save exported charts in `images/` and summarize the findings below.
